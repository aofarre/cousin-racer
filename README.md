# Cousin Racer

Static, dependency-free game (no build step, no Node needed).

- Run: open `index.html` in a browser (or serve the folder with any static server).
- Tests: open `tests/tests.html`; it shows ALL PASSED when the logic checks succeed.
- Winner is chosen uniformly at random per race; on-screen motion is cosmetic. Wins are stored in localStorage (key `cousinRacer.wins.v1`).
- Images live in `assets/` (resized copies of the supplied PNGs).
